# Format:
#   set_N: <template_url_with_episode_1_in_it> <start> to <end>
#
# Rules:
#   • The template URL MUST contain "-episode-<number>" somewhere in the path.
#     The scraper replaces that number with each episode in the range.
#   • Episode range is inclusive: "1 to 500" generates episodes 1, 2, … 500.
#   • Lines starting with # are comments and are ignored.
#   • Blank lines are ignored.
#   • Duplicate generated URLs (same anime+episode+type appearing in two sets)
#     are automatically deduplicated — each URL is only scraped once.
#   • Sets are processed in the order they appear in this file.
#   • Custom-set URLs are always scraped BEFORE the bulk list.
#
# ─────────────────────────────────────────────────────────────────────────────
